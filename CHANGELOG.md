# Changelog

## Unreleased

## 0.1.1

- Published the SDK and MCP packages under the public `@soulsniper-v2` npm organization scope.
- Added tag-driven npm Trusted Publishing with GitHub Actions provenance.
- Preserved executable CLI entrypoints in npm package manifests.
- Updated docs, skill instructions, examples, and machine-readable routes to the canonical scoped package names.

## 0.1.0

- Added the provider-neutral browser client.
- Added Browserbase, Cloudflare Browser Run, Browserless, Steel, and local adapters.
- Added session helpers, cumulative retries, failover trails, typed errors, CLI, memory provider, and agent tools.
- Added the stdio MCP server, agent skill, docs site, raw Markdown docs, LLM index, JSONL feed, and schema map.
- Added first-class Fumadocs MDX documentation sourced from `docs/`.
- Added `npx @soulsniper-v2/browser-sdk <url>`, `doctor`, and `skill` CLI commands.
- Added a stateful MCP browser runtime with explicit actions, accessibility refs, screenshots, allowlists, and cleanup.
- Added opt-in Anchor Browser, Hyperbrowser, and Browser Use Cloud adapters.
- Corrected Browserbase Fetch, Cloudflare DevTools sessions, Browserless REST sessions, and Steel mappings against current provider APIs.
